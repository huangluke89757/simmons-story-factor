# simmons-story-factor

基于安妮特·西蒙斯《故事思维》（*Whoever Tells the Best Story Wins*）挖掘生成的 WorkBuddy 技能包。

> 道理只能赢得辩论，故事可以收服人心。

## 这是什么
把西蒙斯「用故事获取影响力」的方法论固化成可随时调用的工具箱。当你需要说服、建立信任、处理抵触、落地组织文化时，它能按场景给你对应的故事框架，而不是干讲道理。

## 有啥价值
- **从讲道理到讲故事**：事实不会自己说话，先搭故事沟渠，事实才流得进对方脑子
- **11 个场景化框架**：建立信任、讲好故事、处理抵触、文化落地全覆盖
- **从推力到拉力**：不靠职位硬推，靠故事让人自愿得出结论（合气道原理）
- **含禁忌清单**：明确什么不能讲（恐吓、羞辱、自视高人一等）

## 怎么用（触发词）
- 描述场景：「我要向上司汇报延期，怎么开口？」
- 问框架名：「六个故事」「故事之饵」「六种难缠的人」
- 指定章节：`ch01` ~ `ch11`
- 快速决策：读 `cheatsheet.md` 的故事选择决策树

## 核心框架
1. **六个故事** — 我是谁 / 我为何而来 / 愿景 / 教学 / 行动价值 / 我知道你们在想什么
2. **顺序原则** — 先故事后事实，没好故事宁可不说话
3. **拉力而非推力** — 让人自愿得出结论，而非被说服
4. **六种难缠的人** — 吹毛求疵 / 愤恨 / 嫉妒 / 绝望 / 冷漠 / 贪婪

## 目录结构
- `SKILL.md` — 是什么 / 价值 / 怎么用 + 框架索引 + 章节索引 + 主题索引
- `chapters/` — 11 章正文（ch01 六故事框架、ch03 故事胜于事实、ch07 六种难缠的人、ch11 日出案例等）
- `cheatsheet.md` — 故事选择决策树、抵触诊断表、讲述自检清单、8 条犯错红旗
- `patterns.md` — 16 个可直接套用的技巧
- `glossary.md` — 30+ 术语速查
