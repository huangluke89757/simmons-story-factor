# Chapter 9: 讲故事者该做的和不该做的

## Core Idea
**影响力是把双刃剑。** 会讲故事意味着承担责任——你的翅膀是蜡做的，飞得离太阳太近就会坠落。本章是全书最明确的**伦理与禁忌清单**。

## Frameworks Introduced

- **伊卡洛斯法则（慎用魔力）**
  - When to use: 当你发现自己拥有很强影响力、听众着迷时。
  - How: 记住**你的翅膀是蜡做的**；保持责任感与道德感约束。
  - Why: 有本事而没有责任感约束的人，会发生伊卡洛斯式的悲剧。
  - 从业者自白：一位故事讲述者面对人们着迷的面孔，忍不住祈祷："上帝啊，他们现在处在我的掌握之中，我该怎么办？"

- **四条硬禁忌**
  1. **不要自视高人一等** —— 任何清高自大的态度都是对他人公然的不尊重。后果不是让人**反感**，就是让人**依赖**（你想要盲目的追随者吗？）。
  2. **不要吓唬听众**。
  3. **不要让他们有负罪感**。
  4. **不要让听众觉得无趣**。

- **该做的三件事**
  - **引诱你的听众**（不是灌输）
  - **利用人性与听众沟通**
  - **让听众感受到希望**

- **影响力的伦理边界**
  - 禁止：用故事骗人钱财、致人被开除、获取不应得的奖励、为不道德的目的影响别人。
  - 应为：利用故事和影响力**帮助别人**——使他们的生活更好、更有意义、更轻松、更健康、更有趣。
  - 判据：**当你真心希望让自己和自己周围的人生活更好时，你的生活才会更幸福。**

- **避免制造依赖**
  - Why: 让人对你产生依赖看似成功，但现实世界中，依赖"了不起"的领导后果是灾难性的。
  - How: 故事应该激发听众**朝一个方向、富有创造性地思考**，而不是让他们只会问"接下来我该怎么做？"

## Key Concepts

- **伊卡洛斯神话**：父亲警告"千万不要飞得离太阳太近"，伊卡洛斯沉浸在飞行荣耀中，没察觉石蜡融化，最终坠落身亡，被一堆石蜡和羽毛掩埋。
- **金手指迈达斯国王**：与伊卡洛斯同类的告诫——**小心拥有能力的危险**。
- **微妙的平衡**：在按主观意愿影响他人、使其朝"好"的方向改变的同时，**还要注意对他们保持尊重**。
- **谦逊前提**：即使你认为自己的故事更好、更有效、更符合伦理，**你无法百分之百肯定确实如此**。
- **负罪感的杀伤力**（见 Worked Example）。

## Mental Models

- **把影响力想成飞行** —— 能飞不等于该飞到太阳边；**记住翅膀是蜡做的**。
- **把听众想成需要"被点燃"而非"被填满"的人** —— 引诱 > 灌输。
- **把成功想成"让他们自己思考"，不是"让他们依赖你"**。

## Anti-patterns

- **用负面数据制造恐惧与负罪感** → 毁掉所有积极能量（见 Worked Example）。
- **自视高人一等** → 要么让人反感，要么让人依赖；两者都带来麻烦。
- **追求盲目的追随者** → 等级分明、可预料结果的世界里或许有效，现实中是灾难。
- **操纵别人谋私利** → 既不明智也不聪明；故事会产生坏的结果。
- **让故事无聊** → 等于放弃影响力。

## Worked Example

**场景**：东欧一次国际会议上，一位联合国退休人员（一生致力于环保与反战）演讲。此前一位匈牙利演说家的诙谐开场让全场情绪高涨。

**他的做法**：此后一小时，他用数据描述奄奄一息的婴儿、正在消失的雨林、不断扩散的核武器。

**结果**：会场弥漫着**负罪感、恐惧和耻辱**，消极能量**冲刷掉了早上所有的积极能量**。

**反思**：
- **他说的都是事实。**
- 但**他的故事中的事实使人丧气、使人失去动力**。
- 他想用这样的事实**激励行动**，却不知**消极的故事已经毁了一切**。

**对照原则**：让听众感受到**希望**，而不是负罪感。

## Key Takeaways

1. **记住你的翅膀是蜡做的** —— 影响力越强，越要慎用。
2. **不要吓唬听众，不要让他们有负罪感** —— 负面数据会毁掉积极能量。
3. **不要自视高人一等** —— 后果是让人反感或让人依赖。
4. **不要让听众无趣**；要引诱、要给他们希望。
5. 操纵谋私利既不明智也不聪明；用故事**帮助别人**。
6. 目标是激发听众**创造性地思考**，不是让他们依赖你。
7. 即使你认为自己的故事更好，也**无法百分之百肯定**。
